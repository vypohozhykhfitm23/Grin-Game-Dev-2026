Концепт-документ гри

Назва гри: Grinchenko Flappy Bird

Основна дія: Натискання в правильний момент, щоб підняти персонажа і уникнути перешкоди

Схема керування: Одна кнопка (Space / ЛКМ).Мета гри: Пролетіти крізь якомога більшу кількість перешкод, не торкаючись їх

Правила: Гравітація тягне пташку вниз; кожне натискання дає імпульс вгору; зіткнення з трубою або землею зупиняє гру


Формула:

Тиск: Гравітація та рухомі перешкоди

Обмеження: Траєкторії та вузький простір між трубами

Наслідок: Програш і закінчення ігрової сесії

Core Loop: Стрибок -> Ухилення -> Набір очок -> Рестарт

Стиль і атмосфера: 2D піксельна аркада

Монетизаційна модель: 25¢ за одну сесію (класична аркадна модель)
