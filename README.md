1. Які типи колізій використані?
У проєкті використано два типи колізій. OnTriggerEnter2D застосовується на підборах (листочок-монета), важелі, дверях та WinZone - тобто скрізь де потрібна реакція на одноразовий дотик без фізичного відштовхування. OnTriggerStay2D використовується у FireDamageZone щоб шкода наносилась постійно поки гравець стоїть у вогні, а не лише при першому торканні. OnCollisionEnter2D присутній у базовій механіці руху гравця для визначення землі

2. Де застосовано Raycast або Overlap?
Physics2D.OverlapCircle використовується в скрипті Player.cs для перевірки чи знаходиться гравець на землі - кожен кадр кидається коло з точки _groundCheck з радіусом _groundCheckRadius проти шару _groundLayer. Якщо коло перетинає колайдер землі - гравець може стрибати

3. Чому саме такий метод перевірки обрано?
OverlapCircle для перевірки землі обраний тому що він простий, дешевий по продуктивності і добре працює для округлих основ персонажа. Raycast у цьому випадку менш надійний - при русі вздовж похилих поверхонь він може не спрацювати, тоді як коло охоплює ширшу зону контакту. Trigger-колізії для взаємодій обрані тому що вони не впливають на фізику і дозволяють реагувати на вхід в зону без відштовхування об'єктів

4. Як механіки впливають на core loop?
Core loop гри виглядає так: гравець рухається по рівню, збирає листочки (монети) щоб збільшити рахунок, уникає вогню щоб не втратити HP, знаходить важіль щоб відкрити двері, і виходить через двері щоб виграти. Якщо HP падає до нуля - з'являється Game Over і можна перезапустити сцену. Таким чином кожна механіка має роль: HP створює ризик, монети дають мотивацію досліджувати рівень, важіль і двері формують умову перемоги, а перезапуск замикає петлю

Створені скрипти:

GameManager.cs - розширений існуючий скрипт. Додано систему стану гри через enum GameState (Playing, GameOver, Win), зупинку часу через Time.timeScale, показ панелей Game Over і Win, та перезапуск сцени через RestartScene()

FireDamageZone.cs - новий скрипт. Вішається на GameObject вогню, через OnTriggerStay2D знімає HP гравцю раз на секунду поки той стоїть у вогні

DeathZone.cs - новий скрипт. Невидима зона під рівнем, при падінні в яку гравець миттєво гине через TakeDamage на повний HP

WinZone.cs - новий скрипт. Перевіряє чи був активований важіль через IsActivated, і лише тоді викликає перемогу при вході гравця в зону

PlayerHealthUI.cs - новий скрипт. Відображає HP гравця через UI Slider і TMP текст, змінює колір заповнення з зеленого на жовтий і червоний залежно від відсотку HP

Lever.cs - розширений існуючий скрипт. Додано публічну властивість IsActivated яка стає true після взаємодії гравця з важелем

Doors.cs - змінений існуючий скрипт. Замість перезавантаження сцени тепер викликає SetWin(), і працює лише якщо _isOpen = true
